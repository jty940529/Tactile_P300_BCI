# Tactile_P300_BCI
This is a repository of the scripts used for the study: “Concurrent control of natural and robotic limbs through a tactile-encoded brain-computer interface”.

The scripts include the online EEG preprocessing, online decoding, and P300 signal plotting functions. 

Tactile BCI data for this study are publicly available at https://doi.org/10.5281/zenodo.17306307.
